InnoCount KeyPoint Frozen v2
FINAL CLASS-SPECIFIC SEMANTIC KEYPOINT SCHEMA v2.0
===================================================

STATUS: FROZEN

This document is the final semantic annotation contract for
InnoCount_KeyPoint_Frozen_v2.

The semantic reference frame is the geometry of the steel profile.
It is NOT the orientation of the image.

Therefore terms such as left/right/top/bottom are intentionally avoided.

1. CHANNEL
----------

K1 = opening corner 1
K2 = opening corner 2
K3 = opening corner 3
K4 = opening corner 4

Definition:
Four consecutive corners of the channel opening, in the established
dataset perimeter order.

Skeleton:
K1 -- K2
K2 -- K3
K3 -- K4


2. T-BEAM
---------

K1 = flange centre / web-flange intersection
K2 = flange end 1
K3 = flange end 2
K4 = web end opposite the flange

Definition:
The web-flange junction, the two flange ends, and the distal web end.

Skeleton:
K1 -- K2
K1 -- K3
K1 -- K4


3. HI-BEAM
----------

K1 = flange 1 centre / web-flange intersection
K2 = flange 1 end 1
K3 = flange 1 end 2

K4 = flange 2 centre / web-flange intersection
K5 = flange 2 end 1
K6 = flange 2 end 2

Definition:
Two opposite flange landmarks. Each flange is represented by its
web-flange intersection and its two flange ends.

Skeleton:
K1 -- K2
K1 -- K3
K1 -- K4
K4 -- K5
K4 -- K6


4. ANGLE BAR
------------

K1 = apex / heel
K2 = leg end 1
K3 = leg end 2

Definition:
The angle-profile apex/heel and the two free ends of its legs.

Skeleton:
K1 -- K3
K1 -- K2

IMPORTANT PROVENANCE:
K3 retains source name new-point-3.
Roboflow deleted new-point-2 during labeling.
Do NOT rename K3 to new-point-2.


5. SHEET PILE
------------

K1 = profile corner 1
K2 = profile corner 2
K3 = profile corner 3
K4 = profile corner 4

Definition:
Four consecutive corners of the visible sheet-pile profile, in the
established dataset perimeter order.

Skeleton:
K1 -- K2
K2 -- K3
K3 -- K4


COORDINATE / VISIBILITY RULES
=============================

Coordinate system:
    origin = top-left
    x = right
    y = down
    units = source-image pixels

Visibility:
    0 = not labeled
    1 = labeled but not visible / occluded
    2 = visible

Out-of-image:
    retain original coordinate
    do not clip

Out-of-bbox:
    retain original coordinate
    do not clip

No annotation correction is performed by this schema.


EXPERIMENTAL RULES
==================

1. Frozen v2 is the sole source dataset.
2. The train/valid/test membership is fixed.
3. All models use the same split.
4. Validation and test annotations are not augmented.
5. Model-specific conversions must preserve the semantic meaning above.
6. Any framework-specific padding/masking must be documented explicitly.
7. No silent semantic remapping is permitted.
